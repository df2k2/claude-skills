# HTML5 input types

Choosing the right input type does more than only validate the input and provide native error messages, it also will change the keyboard input for mobile devices.
If there is an input type that matches your requirements, that often is all that is needed.

HTML5 Input Types

- [email](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/email)
- [search](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/search)
- [tel](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/tel) (for telephone numbers)
- [url](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/url)
- [number](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/number)
- [range](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/range)
- [datetime-local](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/datetime-local)
- [month](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/month)
- [time](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/time)
- [week](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/week)
- [color](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/color)

Depending on the type, other attributes can be added to the input element to further constrain the allowed value.

Input Type Attributes

All input types can have a [required](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/required) attribute.
The list below is not exhaustive, please refer to the [HTML5 Input Attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input#attributes) documentation for more information.

- [email](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/email): [pattern](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/pattern), [multiple](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/multiple)
- [search](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/search): [pattern](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/pattern)
- [tel](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/tel): [pattern](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/pattern)
- [number](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/number): [min](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/min), [max](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/max), [step](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/step)
- [range](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/range): [min](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/min), [max](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/max), [step](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/step)
- [datetime-local](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/datetime-local): [min](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/min), [max](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/max), [step](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/step)
- [month](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/month): [min](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/min), [max](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/max), [step](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/step)
- [time](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/time): [min](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/min), [max](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/max), [step](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/step)
- [week](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/week): [min](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/min), [max](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/max), [step](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/step)
- [color](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/color)
