# Upgrading to 1.3.12

This release is an important security release.

Please refer to the [changelog](changelog-1.x.html#1312-2026-07-13) for details.

Please check the [upgrade process overview](index.html#hyva-checkout-upgrade-process) for Hyvä-Checkout first.

Then, to upgrade, run the command:

```
composer update --with-dependencies hyva-themes/magento2-hyva-checkout:1.3.12
```
