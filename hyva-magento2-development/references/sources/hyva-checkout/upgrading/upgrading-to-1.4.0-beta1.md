# Upgrading to 1.4.0-beta1

Beta release - not for production use

Hyvä Checkout `1.4.0-beta1` is a beta intended for testing and evaluation only. Do **not** run it on a production store. Install it in a development or staging environment so you can validate the new behavior ahead of a stable release.

This is the first beta release of Magewire v3 for Hyvä Checkout

This version introduces significant architectural improvements and laying the foundation for future releases.

Please refer to the [changelog](changelog.html#140-beta1-2026-06-30) for details.

Please check the [upgrade process overview](index.html#hyva-checkout-upgrade-process) for Hyvä-Checkout first.

Then, to upgrade, run the command:

```
composer update --with-dependencies hyva-themes/magento2-hyva-checkout:1.4.0-beta1
```

Upgrade guide coming soon

We're preparing a comprehensive upgrade guide that will cover the recommended upgrade process & migration steps.
