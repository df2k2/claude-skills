# Upgrading to 1.4.0-beta6

Beta release - not for production use

Hyvä Checkout `1.4.0-beta6` is a beta intended for testing and evaluation only. Do **not** run it on a production store. Install it in a development or staging environment so you can validate the new behavior ahead of a stable release.

This is a maintenance release focused on an important security fix.

Please refer to the [changelog](changelog.html#140-beta6-2026-10-06) for details.

Please check the [upgrade process overview](index.html#hyva-checkout-upgrade-process) for Hyvä-Checkout first.

Then, to upgrade, run the command:

```
composer update --with-dependencies hyva-themes/magento2-hyva-checkout:1.4.0-beta6
```
