# Upgrading to 1.3.13

This is a maintenance release focused on important bug fixes.

We highly recommend upgrading to this version if you are on `1.3.12`, as it resolves issues introduced in that release.

Please refer to the [changelog](changelog-1.x.html#1313-2026-08-14) for details.

Please check the [upgrade process overview](index.html#hyva-checkout-upgrade-process) for Hyvä-Checkout first.

Then, to upgrade, run the command:

```
composer update --with-dependencies hyva-themes/magento2-hyva-checkout:1.3.13
```
