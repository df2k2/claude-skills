# What is Hyvä?

Hyvä is a product suite for Magento 2 and Adobe Commerce. It started as a frontend theme, and today it also covers the checkout, content management, and the admin panel.

## The Hyvä Theme

Hyvä Themes offers a Magento frontend, built from scratch, using the Magento templating system, but written entirely from the ground up.

It offers all the tools Magento developers already know and love (layout XML, blocks, view models and phtml), but without the parts they don't like (UI-components, Knockout, RequireJS, less CSS). In their place, Hyvä uses [Tailwind CSS](../hyva-themes/working-with-tailwindcss/index.html) and [Alpine.js](../hyva-themes/working-with-alpinejs/index.html).

## Why Hyvä Exists

Hyvä Themes was built with a focus on performance and reduced complexity, meaning you get a faster webshop while saving development hours on customizations. And it makes developers happier.

Hyvä offers a great alternative to Single-Page-Applications (SPAs), usually delivering faster websites using less budget, while using tools most Magento developers already know.

The reasoning behind these choices is described in our [Technical Vision](technical-vision.html).

## More Than a Theme

The theme is the foundation the rest of the suite builds on.

- **[Hyvä Checkout](../hyva-checkout/index.html)** replaces the Magento checkout with a server rendered checkout built on Magewire. It can be enabled per store view, so you can roll it out gradually.
- **[Hyvä Commerce](../hyva-commerce/index.html)** bundles the theme and the checkout with merchant facing features such as Hyvä CMS, the Admin Dashboard, Menu Builder, and Media Optimization.
- **[Hyvä Enterprise](../hyva-enterprise/index.html)** adds compatibility with Adobe Commerce, the B2B suite, and Adobe services such as Live Search and Product Recommendations.
- **[Hyvä UI Library](../hyva-ui-library/what-is-the-hyva-ui-library.html)** is a set of accessible, Tailwind styled components you copy into your theme, with a matching Figma file for designers.

The Hyvä Theme is open source. The other products are commercial, distributed through a private Composer repository, with licenses managed in the [Hyvä Portal](the-hyva-portal/index.html).

## Where to Start

Install the theme first, since every other product builds on it. Registering in the Hyvä Portal is free and gives you the packagist.com key the installation needs.
