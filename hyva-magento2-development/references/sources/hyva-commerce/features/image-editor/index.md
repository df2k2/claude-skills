# Image Editor

Image Editor, included with [Hyvä Commerce](https://www.hyva.io/hyva-commerce.html), is an easy-to-use tool integrated into the Magento admin. It lets content creators perform basic image transformations such as resizing, cropping, flipping, fine-tuning, and applying filters. It supports `JPEG (JPG)` and `PNG` images and can be used anywhere the Media Gallery is available, including within [Hyvä CMS](../cms/index.html).

Available with Hyvä Commerce 1.0.0

Image Editor is generally available since `1.0.0`, which shipped with Hyvä Commerce `1.0.0`. See [Installation](installation.html) for setup.

[![Image Editor](./images/image-editor.jpg)](./images/image-editor.jpg)

Image Editor is built on a forked version of [Filerobot Image Editor](https://github.com/scaleflex/filerobot-image-editor).

## Installing Image Editor

Ready to get started? Follow [Installing Image Editor](./installation.html) to add it to your Magento store.
