# Admin Dashboard

Admin Dashboard is a revitalization of the Magento Admin Panel's landing page, offering a range of widgets that allow admin users to create personalized dashboards with content relevant to them.

Available with Hyvä Commerce 1.2.0

Admin Dashboard is generally available since `1.0.0`, which shipped with Hyvä Commerce `1.2.0`. [Dashboard Views & Roles](dashboard-views.html) arrived in Admin Dashboard `2.0.1`, which shipped with Hyvä Commerce `1.3.0`. See [Installation](installation.html) for setup.
